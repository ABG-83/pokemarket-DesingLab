
# PokéMarket

PokéMarket es una plataforma digital para la gestión, valoración y comercialización de cartas coleccionables Pokémon, orientada al mercado latinoamericano.

## Funcionalidades principales

- Catálogo de cartas con precios diferenciados según edición, idioma y grado de conservación.
- Sistema de subastas con historial público y verificable.
- Herramientas de inteligencia de mercado, seguimiento de precios y análisis de tendencias.
- API de precios para tiendas y clientes empresariales.

## Objetivo del proyecto

Desarrollar una plataforma que facilite el acceso a información confiable sobre el valor de las cartas Pokémon y proporcione herramientas especializadas para coleccionistas, vendedores y empresas.
